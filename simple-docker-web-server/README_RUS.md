# Simple Docker

## Реализованный функционал

### Часть 1: Работа с готовыми Docker-образами

#### Управление контейнерами nginx
- Загружен официальный Docker-образ nginx с использованием команды `docker pull nginx`
- Проверена доступность образов через команду `docker images`
- Запущен контейнер в фоновом режиме с помощью `docker run -d nginx`
- Проверен статус запущенных контейнеров командой `docker ps`
- Исследована детальная информация о контейнере через `docker inspect`
- Определены ключевые характеристики контейнера: размер, сопоставленные порты и IP-адрес
- Управление жизненным циклом контейнера через `docker stop` и `docker restart`
- Настроено сопоставление портов для доступа к nginx на локальной машине
- Проверена доступность стартовой страницы nginx через веб-браузер

### Часть 2: Операции с контейнерами и конфигурацией

#### Управление конфигурацией nginx
- Получен доступ к оболочке контейнера через `docker exec` для изучения конфигурации nginx
- Создан пользовательский конфигурационный файл nginx на хост-системе
- Реализована конфигурация страницы статуса сервера для эндпоинта /status
- Передача конфигурационного файла в контейнер с помощью `docker cp`
- Перезапуск службы nginx внутри контейнера для применения новой конфигурации
- Проверка функциональности страницы статуса по адресу localhost:80/status
- Выполнены операции экспорта/импорта контейнера через `docker export` и `docker import`
- Управление процессами удаления и восстановления контейнеров и образов

### Часть 3: Разработка пользовательского веб-сервера

#### Реализация приложения на FastCGI
- Разработан веб-сервер на языке C с использованием протокола FastCGI
- Реализована функциональность ответа "Hello, World!"
- Настроен spawn-fcgi для запуска приложения на порту 8080
- Создана конфигурация обратного прокси nginx для маршрутизации с порта 81 на 8080
- Протестирована сквозная функциональность с доступом через браузер
- Организована структура конфигурационных файлов проекта для интеграции с Docker

### Часть 4: Создание пользовательских Docker-образов

#### Многоэтапный процесс сборки Docker
- Разработан Dockerfile с оптимизированной структурой слоев
- Реализована компиляция исходного кода в процессе сборки
- Настроена интеграция nginx с пользовательским приложением FastCGI
- Управление экспортом портов и координацией служб
- Собран пользовательский образ с определенными тегами с помощью `docker build`
- Проверено создание образа и корректность его функционирования
- Реализовано сопоставление томов для динамических обновлений конфигурации
- Добавлено проксирование страницы статуса nginx в конфигурацию

### Часть 5: Оценка безопасности контейнеров

#### Усиление безопасности Docker-образов
- Выполнено сканирование безопасности с использованием инструмента оценки уязвимостей Dockle
- Выявлены и устранены проблемы безопасности в конфигурации контейнера
- Внедрены лучшие практики безопасности контейнеров
- Устранены предупреждения и ошибки из результатов сканирования безопасности
- Оптимизирован Dockerfile в соответствии с рекомендациями CIS benchmarks

### Часть 6: Оркестрация многоконтейнерных приложений

#### Реализация Docker Compose
- Разработан docker-compose.yml для многосервисного приложения
- Настроены межконтейнерные сети и коммуникация
- Реализован обратный прокси nginx между контейнерами
- Управление сопоставлением портов для внешнего доступа
- Выполнены процессы сборки и развертывания с использованием команд Docker Compose
- Проверена полная функциональность приложения через тестирование в браузере
