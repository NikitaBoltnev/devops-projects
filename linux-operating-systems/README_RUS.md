# Операционные системы UNIX/Linux (Базовый)

## Реализованный функционал

### Часть 1: Установка операционной системы
- Успешно установлена Ubuntu 20.04 Server LTS без графического интерфейса
- Проверена версия системы с помощью терминальных команд
- Подтверждена установка серверной редакции без компонентов рабочего стола

### Часть 2: Управление пользователями
- Создана дополнительная учетная запись пользователя
- Пользователь добавлен в группу adm для системных привилегий
- Проверено создание пользователя через системные файлы конфигурации
- Реализованы правильные практики управления пользователями

### Часть 3: Настройка сети
- Настроено сетевое имя системы согласно спецификациям
- Установлен корректный часовой пояс для географического местоположения
- Определены и задокументированы сетевые интерфейсы, включая loopback
- Получен динамический IP-адрес через протокол DHCP
- Определены адреса внутреннего и внешнего шлюзов
- Реализована статическая сетевая конфигурация
- Проверена сетевая связность через успешные ping-тесты

### Часть 4: Управление пакетами системы
- Выполнено комплексное обновление системных пакетов
- Достигнуто полностью обновленное состояние системы
- Подтверждено завершение обновления через проверку статуса пакетного менеджера

### Часть 5: Работа с привилегиями sudo
- Настроены привилегии sudo для дополнительной учетной записи
- Объяснен принцип делегирования привилегий в Unix-подобных системах
- Продемонстрировано выполнение административных задач с помощью sudo
- Изменено сетевое имя системы через привилегированного пользователя

### Часть 6: Служба синхронизации времени
- Установлена и настроена автоматическая синхронизация времени
- Проверены корректные настройки часового пояса и отображения времени
- Подтвержден статус NTP-синхронизации через системные сервисы
- Обеспечено точное время во всех системных операциях

### Часть 7: Работа с текстовыми редакторами
- Установлены несколько текстовых редакторов (VIM плюс два дополнительных)
- Продемонстрированы возможности создания и редактирования файлов в разных редакторах
- Освоены редакторо-специфичные команды для сохранения изменений и выхода
- Реализован функционал поиска и замены текста в каждом редакторе
- Сравнены различия в рабочих процессах между различными средами редактирования

### Часть 8: Настройка SSH-сервиса
- Установлен и настроен SSH-демон
- Реализован автоматический запуск сервиса при загрузке системы
- Изменен порт сервиса по умолчанию для повышения безопасности
- Мониторинг процессов сервиса с помощью системных утилит
- Проверена доступность сервиса через проверку сетевых портов
- Задокументирована сетевая конфигурация и статус сервиса

### Часть 9: Системные утилиты мониторинга
- Установлены и использованы утилиты мониторинга системы top и htop
- Проанализированы метрики производительности системы
- Идентифицированы ресурсоемкие процессы и паттерны системной нагрузки
- Настроены пользовательские интерфейсы отображения и фильтрации
- Сравнена функциональность между базовыми и продвинутыми инструментами мониторинга

### Часть 10: Управление дисками
- Исследована конфигурация дисков с помощью утилит управления разделами
- Задокументированы спецификации устройств хранения данных
- Определено распределение и конфигурация swap-пространства

### Часть 11: Анализ файловой системы
- Проанализировано использование дискового пространства и статистика файловой системы
- Отслежено использование корневого раздела и доступное пространство
- Сравнены форматы вывода между различными опциями команд
- Определены типы файловых систем и единицы измерения

### Часть 12: Анализ размера директорий
- Измерены размеры директорий с помощью утилит использования диска
- Сгенерированы отчеты в нескольких форматах вывода
- Проанализировано содержимое отдельных директорий с детализированной разбивкой
- Сравнено потребление хранилища между системными директориями

### Часть 13: Интерактивный анализ использования диска
- Установлен и использован интерактивный анализатор использования диска
- Проверены измерения размеров директорий против предыдущих методов
- Продемонстрировано графическое представление распределения хранилища
- Сравнена эффективность между различными инструментами анализа дисков

### Часть 14: Анализ системных логов
- Исследованы различные системные файлы журналов для диагностики и мониторинга
- Извлечена информация об аутентификации пользователей и паттернах входа
- Отслежены операции системных сервисов и события перезапуска
- Идентифицированы события, связанные с безопасностью, и системные сообщения

### Часть 15: Планирование заданий
- Настроено автоматическое выполнение задач с помощью планировщика cron
- Проверено выполнение задач через мониторинг системных журналов
- Управление списками запланированных заданий и конфигурациями
- Реализованы правильные процедуры планирования и удаления заданий
