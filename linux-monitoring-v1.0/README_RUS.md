# Linux Monitoring v1.0

## Реализованный функционал

### Часть 1: Валидация входных параметров
Разработан bash-скрипт с комплексной проверкой входных данных:
- Реализована проверка наличия обязательного параметра
- Добавлено определение числового ввода с выводом соответствующего сообщения об ошибке
- Создана система понятных сообщений о некорректном вводе
- Настроены корректные коды завершения скрипта для различных сценариев

### Часть 2: Комплексный сбор системной информации
Создан скрипт для детального анализа системы со сбором множества метрик:

**Идентификационные данные системы:**
- Получение сетевого имени хоста
- Определение временной зоны со смещением UTC
- Идентификация текущего пользователя
- Определение типа и версии операционной системы

**Временные характеристики:**
- Форматирование текущей даты и времени
- Расчет времени работы системы в читаемом формате
- Точное преобразование времени работы в секунды

**Сетевая конфигурация:**
- Извлечение IP-адреса из сетевых интерфейсов
- Форматирование и валидация сетевой маски
- Определение шлюза по умолчанию

**Анализ использования памяти:**
- Расчет общего объема ОЗУ с точностью до 3 знаков
- Количественное определение используемой памяти
- Измерение доступной памяти
- Конвертация всех значений памяти в ГБ

**Мониторинг дискового пространства:**
- Анализ размера корневого раздела в МБ с точностью 2 знака
- Расчет использованного пространства на корневом разделе
- Измерение свободного пространства на корневом разделе

**Функционал сохранения данных:**
- Интерактивный запрос пользователя на сохранение
- Соглашение об именовании файлов с использованием временных меток
- Автоматическое создание файлов в текущей директории
- Обработка ответов без учета регистра (Y/y для подтверждения)

### Часть 3: Продвинутое визуальное форматирование
Улучшен скрипт исследования системы с добавлением возможностей цветового оформления:

**Система цветовых параметров:**
- Реализована 4-параметровая цветовая конфигурация (значения 1-6)
- Цветовая схема: 1-белый, 2-красный, 3-зеленый, 4-синий, 5-пурпурный, 6-черный
- Разделение цветов фона и шрифта для заголовков и значений

**Валидация входных данных и предотвращение конфликтов:**
- Добавлено обнаружение конфликтов между фоном и текстом
- Реализована комплексная проверка параметров
- Созданы понятные сообщения об ошибках с инструкциями
- Корректное завершение скрипта при ошибках валидации

**Визуальные особенности:**
- Раздельные цветовые схемы для заголовков столбцов и данных
- Сохранена вся функциональность вывода системной информации
- Обеспечена точность данных при добавлении визуальных улучшений

### Часть 4: Система управления конфигурационными файлами
Создан гибкий подход к конфигурации с использованием внешних файлов:

**Структура конфигурационного файла:**
- Определена четкая система именования параметров
- Реализована система подстановки значений по умолчанию
- Создан надежный парсинг конфигурации

**Динамическая обработка конфигурации:**
- Автоматическое обнаружение отсутствующих параметров
- Интеллектуальная подстановка значений по умолчанию
- Комплексная валидация конфигурации

**Улучшения пользовательского интерфейса:**
- Добавлен вывод цветовой схемы после системной информации
- Четкая маркировка значений по умолчанию и настроенных
- Сохранена обратная совместимость с параметрическим подходом

### Часть 5: Продвинутый инструмент анализа файловой системы
Разработана комплексная утилита для анализа директорий:

**Анализ структуры директорий:**
- Рекурсивный подсчет папок включая все поддиректории
- Идентификация топ-5 самых больших папок с полными путями
- Расчет общего количества файлов

**Система классификации типов файлов:**
- Обнаружение конфигурационных файлов (.conf)
- Идентификация текстовых файлов
- Распознавание исполняемых файлов
- Анализ лог-файлов (.log)
- Обнаружение архивных файлов
- Подсчет символических ссылок

**Продвинутая аналитика файлов:**
- Топ-10 самых больших файлов с классификацией типов
- Анализ исполняемых файлов с генерацией MD5 хешей
- Мониторинг производительности с измерением времени выполнения

**Форматирование вывода:**
- Четкое структурированное представление с категоризацией
- Корректная конвертация единиц измерения (ГБ/МБ) для отображения размеров
- Последовательная нумерация для ранжированных списков
- Точное измерение времени выполнения
